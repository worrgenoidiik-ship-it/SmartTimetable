# SmartTimetable — неофициальный клиент ЭИОС для iOS и Android

Приложение для [ЭИОС](https://portal.ulsu.ru), которое я, студент 2 курса, делаю вместе с ИИ (Claude, ChatGPT, а раньше Gemini) для себя и одногруппников: расписание, оценки, дедлайны, курсы, сообщения и тесты в одном месте и без тормозов мобильной версии сайта.

> **Неофициальное приложение.** Оно не связано с университетом и не одобрено им. Приложение работает с вашим аккаунтом так же, как браузер: открывает те же страницы и отправляет те же формы. Пользуйтесь на свой риск.

iOS **1.9.5** (Swift, SwiftUI, iOS 17+) · Android **2.0.3** (Kotlin, Jetpack Compose, Android 7+)

---

## Установка

- **Android:** скачайте APK из [Releases](https://github.com/worrgenoidiik-ship-it/SmartTimetable/releases) (релизы с тегом `android-v…`) и установите его. Android попросит разрешить установку из этого источника. Новые версии приложение находит само («Настройки → Обновления приложения») и ставит поверх, без потери входа и данных.
  Если раньше стояла сборка, полученная не отсюда, удалите её один раз перед установкой: у неё другая подпись.
- **iOS:** соберите проект в Xcode (см. «Сборка»). В App Store приложения пока нет.

## Возможности

**Расписание**
- Три источника: план семестра группы (JSON-файл), расписание из ЭИОС и режим «Авто» (план, пока он действует, потом ЭИОС).
- ФИО преподавателей и аудитории подтягиваются из названий курсов и страниц портала.
- Напоминание за 5 минут до пары, виджет на рабочий стол.

**Учёба**
- Оценки и аттестация по семестрам.
- Дедлайны тестов и заданий с напоминаниями, отдельный список просроченных работ.
- Курсы с разделами и материалами.
- Тесты Moodle прямо в приложении: те же поля формы, что и в браузере. Если тип вопроса незнакомый, тест открывается во встроенном браузере.

**Общение и сервисы**
- Чаты и сообщения через AJAX-методы мессенджера Moodle, поиск людей, «Написать преподавателю».
- Уведомления портала, заказ справок, «Задать вопрос».

**Удобство**
- Вход по логину и паролю с поддержкой кода из MAX.
- Face ID при открытии приложения. При сворачивании приложение блокируется, и данные закрываются.
- Темы оформления, своя палитра, новогодний режим.
- Всё работает офлайн из кэша, а обновляется раз в 30–60 минут.

## Сессия, которая не слетает

ЭИОС завершает сессию после периода без активности, а iOS не даёт приложению работать в фоне по таймеру. Поэтому сессия устроена так:

1. Пока приложение открыто, оно само отмечается на портале (`core_session_touch`).
2. Куки сессии хранятся в Keychain и переживают переустановку приложения.
3. **Сервер-пингер** (по желанию, [`Server/keeper`](Server/keeper)): маленький сервис на Python для своего VPS. Раз в 30–60 минут он открывает одну страницу портала с вашей сессией, а если телефон потерял куки, отдаёт сессию обратно приложению. На сервер уходят только куки ЭИОС: пароль и код MAX остаются на телефоне.
4. «Настройки → Журнал сессии» показывает, почему и когда портал попросил войти заново.

## Сборка

**iOS**

1. Xcode 16+, откройте `эиос.xcodeproj`.
2. В Signing & Capabilities выберите свою команду (подойдёт бесплатный Apple ID) и при необходимости поменяйте bundle id и App Group.
3. Запустите схему `SmartTable` на устройстве. Симулятор подходит для интерфейса и тестов, но сам портал из симулятора может быть недоступен.

Тесты: `⌘U` или

```bash
xcodebuild test -project эиос.xcodeproj -scheme SmartTable -destination 'platform=iOS Simulator,name=iPhone 17'
```

**Android** (папка [`Android`](Android))

1. Откройте папку `Android` в Android Studio.
2. Debug-сборка запускается сразу. Для release нужен свой ключ: `Android/signing/keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`). Папка `signing/` в git не попадает.
3. Тесты: `./gradlew testDebugUnitTest`.

Тесты сервера-пингера: `cd Server/keeper && python3 -m unittest test_keeper`.

Свой сервер-пингер: см. комментарии в [`Server/keeper/keeper.py`](Server/keeper/keeper.py) и [`Server/keeper/deploy.sh`](Server/keeper/deploy.sh).

## Конфиденциальность

Коротко: данные хранятся только на вашем телефоне и уходят только на `portal.ulsu.ru` (и, если вы его подключили, на ваш собственный сервер-пингер). Подробно: в [PRIVACY.md](PRIVACY.md).

## История

- **v1.1 (январь 2026):** первая версия, около 1 100 строк. Почти всё в одном `ContentView.swift`, расписание вписано в код, пароль хранился в `UserDefaults`. Она сохранилась в истории этого репозитория.
- **v1.2–1.9.5:** код разнесён по слоям, добавлены тесты, вход с MAX, Keychain, сообщения, тесты Moodle, дедлайны, виджет, долгая сессия и сервер-пингер. Порт на Android (Kotlin, Jetpack Compose) лежит в папке `Android`.

## Как сделан проект

Первую версию я написал сам, разбираясь в Swift с помощью Gemini. Начиная с версии 1.2 большая часть кода написана вместе с ИИ-ассистентами Claude (Anthropic) и ChatGPT (OpenAI): я ставил задачи, проверял всё на своём телефоне и с реальной ЭИОС, находил ошибки и разбирал предложенные решения.
