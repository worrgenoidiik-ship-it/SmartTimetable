# Конфиденциальность

У SmartTimetable нет своего сервера, аналитики, рекламы и трекеров. Автор приложения не получает никаких ваших данных.

## Что хранится на телефоне

**iOS**
| Что | Где | Когда удаляется |
|---|---|---|
| Куки сессии ЭИОС | Keychain, только на этом устройстве, без iCloud | При выходе из аккаунта |
| Логин и пароль (если включено «Входить автоматически») | Keychain, только на этом устройстве | При выходе или если выключить настройку |
| Расписание, оценки, курсы, дедлайны (кэш) | Файл в папке приложения | При выходе из аккаунта |
| Фото профиля, заметки, настройки | Папка приложения и Keychain | При удалении приложения |
| Журнал сессии | Настройки приложения | Кнопкой «Очистить» или при удалении приложения |

Keychain переживает переустановку приложения, поэтому после неё вход сохраняется. Чтобы удалить всё, выйдите из аккаунта перед удалением.

**Android**
| Что | Где | Когда удаляется |
|---|---|---|
| Куки сессии ЭИОС | Системное хранилище WebView в закрытой папке приложения | При выходе из аккаунта или удалении приложения |
| Логин и пароль (если включено «Входить автоматически») | Папка приложения, зашифровано AES-GCM ключом из Android Keystore | При выходе, если выключить настройку, или при удалении приложения |
| Расписание, оценки, курсы, дедлайны (кэш) | Папка приложения, тоже зашифровано | При выходе из аккаунта или удалении приложения |
| Заметки, фото профиля, настройки | Папка приложения | При удалении приложения |

Резервное копирование данных приложения в облако отключено, незашифрованные HTTP-запросы запрещены.

**Обе платформы:** код MAX нигде не сохраняется. Сообщения из чатов не сохраняются, а загружаются при открытии.

## Куда уходят данные
- **`portal.ulsu.ru`**: те же запросы, что делает браузер, когда вы пользуетесь ЭИОС.
- **Ваш сервер-пингер** (только iOS), только если вы его сами подняли и подключили. Туда уходят **только куки ЭИОС** (по HTTPS, с вашим секретным ключом). При выходе из аккаунта приложение просит сервер их удалить. Пароль и код MAX на сервер не отправляются.
- **`api.github.com`**, только Android: не чаще двух раз в сутки приложение проверяет, вышла ли новая версия. Это обычный публичный запрос, без данных о вас и вашем аккаунте.

Больше приложение ни с кем не связывается.

## Важно
Куки сессии дают доступ к вашему аккаунту ЭИОС. Поднимайте сервер-пингер только на сервере, которым управляете сами, и не передавайте его ключ другим людям.
